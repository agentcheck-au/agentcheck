How to check the NSW Name and Shame Register

A licence check and a regulatory history check answer different questions. This guide explains the second step.

Start a free licence check ↗

By AgentCheck · Updated 31 October 2026

What is the register?

The NSW Fair Trading Name and Shame Register publishes regulatory actions in the property sector. Entries can include disciplinary action, licence suspension or cancellation, public warnings and prosecution outcomes.

A current licence does not rule out a published regulatory action. Check the licence record and this separate register.

How to search from AgentCheck

  1. Find and select the correct agent or company licence record.
  2. In Step 2, select “Open Name and Shame Register”. We copy the displayed licence number when your browser permits it.
  3. Paste the number into the official register’s search bar. If needed, search the matching person’s or legal company’s name too.
  4. Read any matching notice, then return to the AgentCheck tab, which stays open.

The official register opens in a separate tab. If copying fails, select the displayed number or use the copying help beside the link. AgentCheck does not search this register for you.

If you find a matching entry

Confirm the name, licence number and relevant dates. Read the action and outcome in the actual notice. A published entry does not automatically establish that a licence is currently suspended or cancelled; check the current licence status separately.

If you find no match or are unsure

No matching entry is not an official all-clear. Check the spelling, licence number and company identity, and contact NSW Fair Trading if you need clarification.

On return, AgentCheck explains the option you select. Your selection is not a finding independently verified by AgentCheck. For the first step, see our agent and agency licence guides.
